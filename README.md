# BPUT Migration Certificate Portal

Web application for searching student records and issuing Migration Certificates for Biju Patnaik University of Technology (BPUT).

## Features
- Search student records by Registration Number
- View migration status and issue Migration Certificates
- Print individual and bulk migration certificates
- Data entry module for student records
- Migration reports generation

## Tech Stack
- ASP.NET Core MVC (.NET 8)
- Repository pattern (IMigrationRepository, IMigrationDataRepository)
- SQL Server
- Bootstrap 5, jQuery
